# hxyfront-62002 剧场灯光Cue表管理

源提示词编号：2

给剧场灯光师在排练期间使用的灯位与 Cue 表管理工具。工作台为「排演模式」：边看舞台平面图边改灯与 Cue，调整实时反映到舞台图和当前场景，并自动存为浏览器本地草稿。

## 功能

- **按光位筛选灯具**：面光 / 侧光 / 逆光 / 效果光，带各光位灯具数量。
- **灯具调整实时联动**：
  - 通道号（1–512，全台唯一，撞通道实时提示并拒绝生效）
  - 色片（色片表统一维护，舞台图灯体与光束颜色随动）
  - 焦点位置（舞台图上直接拖拽橙色焦点，或填坐标，自动夹回舞台台面；可标记待走位确认）
  - 亮度预设（加入新场景时的初始电平）
- **舞台图 + 当前场景同步更新**：选中某条 Cue 后，光束颜色/宽度/透明度按该场景电平渲染，场景面板可逐灯调电平、把灯加入或移出场景。
- **Cue 列表**：新增、行内改名、上移/下移排序；无论怎么调整，序号始终从 1 连续。
- **移除保护**：移除灯具时若仍被 Cue 引用，弹窗列出全部相关 Cue（序号、名称、在该场景的电平）并挡住移除，原灯具与 Cue 顺序原样保留；弹窗可直接跳到对应 Cue 处理。
- **本地草稿**：所有排演调整防抖写入 localStorage（`rehearsal-draft:hxyfront-62002:v1`），刷新不丢；顶部显示保存状态，可一键恢复示例。

## 分层结构

数据、规则、界面分开维护：

```
src/
├─ data/            # 数据层：类型、种子数据、色片表、舞台几何常量、localStorage
│  ├─ types.ts
│  ├─ seed.ts
│  ├─ layout.ts
│  └─ storage.ts
├─ rules/           # 规则层：纯函数，无 React 依赖，可独立测试
│  ├─ limits.ts     #   通道/电平范围与夹取
│  ├─ fixtures.ts   #   光位筛选、通道唯一性、引用检查、移除保护
│  ├─ cues.ts       #   Cue 增改名、重排序号、场景电平
│  └─ stage.ts      #   焦点夹回舞台
├─ model/
│  └─ useRehearsal.ts  # 编排层：状态意图 + 草稿自动保存
├─ ui/              # 界面层：只调用 model 暴露的意图，不内置业务规则
│  ├─ Header.tsx
│  ├─ FixturePanel.tsx
│  ├─ StageMap.tsx
│  ├─ ScenePanel.tsx
│  ├─ CueList.tsx
│  └─ RemoveBlockedDialog.tsx
└─ App.tsx
```
